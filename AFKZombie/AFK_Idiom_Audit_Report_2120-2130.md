## Applying the corrections

Copy the eight HTML files in this ZIP into your local `AFKZombie` folder, replacing the files with the same names, then run your existing full GitHub sync `.bat`. These eight files preserve the original reader CSS, JavaScript, chapter navigation, and all unchanged story paragraphs.

Unmodified chapters **2126, 2127, and 2129** are intentionally not included.
